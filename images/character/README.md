# キャラ立ち絵の差し替え

このフォルダの PNG が、ゲーム画面のキャラパネルに出る立ち絵。
**差し替えたいときは、ここのファイルを描いた絵で上書きするだけ**でいい。

| ファイル | 出るフロア |
| --- | --- |
| `1F-ARCADE.png` | 1F ARCADE |
| `5F-MARKET.png` | 5F MARKET |
| `9F-CLINIC.png` | 9F CLINIC |
| `RF-ROOFTOP.png` | RF ROOFTOP |

今は 4 枚とも同じ絵（`images/new/SPOILER_A.jpg` の下描きを線画にしたもの）が入っている。
フロアごとに描き分けるなら、そのファイルを差し替えればいい。

## 白地の絵をここへ入れる

`tools/RemoveWhiteBackground.java` に通すと、そのままここへ置ける透過 PNG（1080×1080）
になる。**絵の種類で使うモードが違う**。

### 下描き・線画なら `--lineart`

```
java tools\RemoveWhiteBackground.java images\new\SPOILER_A.jpg images\character\9F-CLINIC.png --lineart
```

紙の白地を透明にして、線の濃さをそのまま不透明度に、色を蛍光灯色（`#B7C89A`）にする。
`tools/BuildRoughMocks.java` が構図ラフにかけているのと同じ扱い。

線画は**内側が白い**ので、下の塗り絵モードにかけると体の内側まで背景と見なされて抜ける。
かといって白のまま残すと板のように見えるうえ、黒い線は暗い画面に沈んで読めない。

### 塗ってある絵なら（既定）

```
java tools\RemoveWhiteBackground.java images\character.png images\character\9F-CLINIC.png
```

しきい値で明るい画素を一律に抜くのではなく、**画像の縁から連結している白だけ**を
塗りつぶすので、白衣やハイライトに穴が開かない。加えて、腰に当てた腕と胴の隙間のような
「キャラに囲まれた背景」も拾う。輪郭のアンチエイリアスは半透明にして、
混ざった白を差し引いてある。

### 調整

| オプション | 既定 | 効き方 |
| --- | --- | --- |
| `--lineart` | 切 | 下描き向けモード。`--tolerance` / `--enclosed` は効かなくなる |
| `--tolerance` | 236 | 下げると背景と見なす範囲が広がる。地色にムラがあるとき上げ下げする |
| `--enclosed` | 200 | 下げると小さい閉じ白まで抜く。白衣の中まで抜けたら上げる。0 で無効 |
| `--size` | 1080 | 正方形で出すときの一辺 |
| `--canvas` | − | `1920x1080` のように任意の画布へ。全画面モック用 |
| `--cover` | 切 | 画布を埋めるまで拡大してはみ出しを切る。既定は収める＋上寄せ |

## 決まりごと

- **形式**: PNG（背景は透過にする。パネルの壁紙が透けて見えるのが前提）
- **サイズ**: 1080×1080 を基準にする。縦横比は保たれる（`preserveRatio: true`）ので
  縦長でも構わないが、パネルの長辺に合わせて拡大 → 上端中央そろえで**クリップされる**。
  顔を見せたいなら絵の上寄りに置くこと
- **反映**: 起動時に 1 回だけ読む。置き換えたらアプリを起動し直す
- **戻したいとき**: ファイルを消せば `images/skin/skin-kowloon-<フロア>-character.png`
  （自動生成のシルエット）へ落ちる。消しても壊れない

## 上書きされない

`tools/GenerateSkinImages.java` はこのフォルダへ一切書き込まない。
生成を再実行しても、ここに置いた絵が消えることはない
（代わりに「このフロアはシルエットが表示されない」と知らせる行が出る）。

詳細は [ASSETS.md](../../ASSETS.md) を参照。
