# キャラ立ち絵の差し替え

このフォルダの PNG が、ゲーム画面のキャラパネルに出る立ち絵。
**差し替えたいときは、ここのファイルを描いた絵で上書きするだけ**でいい。

| ファイル | 出るフロア |
| --- | --- |
| `1F-ARCADE.png` | 1F ARCADE |
| `5F-MARKET.png` | 5F MARKET |
| `9F-CLINIC.png` | 9F CLINIC |
| `RF-ROOFTOP.png` | RF ROOFTOP |

今入っているのは `tools/GenerateSkinImages.java` が描いた仮のシルエットをコピーしたもの。
これを下敷きにして描いてもいいし、まるごと別の絵に置き換えてもいい。

## 決まりごと

- **形式**: PNG（背景は透過にする。パネルの壁紙が透けて見えるのが前提）
- **サイズ**: 1080×1080 を基準にする。縦横比は保たれる（`preserveRatio: true`）ので
  縦長でも構わないが、パネルの長辺に合わせて拡大 → 上端中央そろえで**クリップされる**。
  顔を見せたいなら絵の上寄りに置くこと
- **反映**: 起動時に 1 回だけ読む。置き換えたらアプリを起動し直す
- **戻したいとき**: ファイルを消せば `images/skin/skin-kowloon-<フロア>-character.png`
  （自動生成のシルエット）へ落ちる。消しても壊れない

## 上書きされない

`tools/GenerateSkinImages.java` はこのフォルダへ一切書き込まない。
生成を再実行しても、ここに置いた絵が消えることはない
（代わりに「このフロアはシルエットが表示されない」と知らせる行が出る）。

詳細は [ASSETS.md](../../ASSETS.md) を参照。
